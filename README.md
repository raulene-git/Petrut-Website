# Jardinería Ciutuza: website

Spanish-language website for **Jardinería Ciutuza**, a gardening and property-services business. Live at **[jardineriaciutuza.com](https://jardineriaciutuza.com)**.

## What's here

- A single-page site (`index.html`) with sections for the business's services, an introduction and contact details
- Plain **HTML and CSS**, mobile-friendly, with no build step

## Hosting

Served by **GitHub Pages** with a custom domain (`CNAME`). `.nojekyll` makes Pages serve the files as they are.

## Run locally

Open `index.html` in a browser.
